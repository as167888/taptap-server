**角标类型编码**：`icon_type 0`=无角标（42 条）、`2`=小图标角标（6 条，如"首发"）、`4`=广告（8 条）。

## 六、与首页推荐流广告池的重合

搜索页 8 个广告主中 **7 个也出现在首页推荐流竞价位**：心动小镇、梦幻西游、燕云十六声、率土之滨、镇邪人、阴阳师、龙之谷：启程。

仅搜索页独有：**鸣潮**（首页流未观测到）。

说明主流厂商是**跨场景打包投放**（首页信息流 + 搜索热搜 + 热点话题），共用同一批素材与预算。

## 七、与首页推荐流广告体系的对比

| 维度 | 首页推荐流（landing/v9） | 搜索页（search/v4） |
|---|---|---|
| 广告标志字段 | `is_ad:true` + `ad_info.material_id` | `property:"ad"` + `ad_id:"appid;trackid"` |
| 未标注广告 | `source=pcebid` / 帖子广告（`flow_cpm`） | `plan_id` + `flow_cpm`（app_id=0 的活动词） |
| 可见角标 | `rec_info type=ad` / 橙色 AD | `icon_type=4` + `icon_title:"广告"`（部分缺失） |
| 竞价字段 | `flow_cpm`、`uuid`、`pctr/pcvr` | `flow_cpm`、`pctr`、`plan_id`、`track_id` |
| 本批价格 | 首批批次价 19.83 元 | 未标注广告批次 7.21 元 |

## 八、可扩展的监测方向

- 本次只抓了**搜索框默认页**；输入关键词后的**搜索结果页**是另一个接口，广告位与标志规则需单独验证；
- 搜索页的未标注活动词（`plan_id` 机制）是继首页 `pcebid` 之后**第二种"付费但无标志"的形态**，可纳入现有监测体系统计占比。
